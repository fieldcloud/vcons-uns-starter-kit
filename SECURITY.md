# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Instead, email the maintainers with:
- a description of the issue
- steps to reproduce
- suggested remediation (if you have one)

We will acknowledge receipt and coordinate a fix.

## Data safety (important)

This repository is intended for proof-of-concept / hackathon builds.

Do **not** commit:
- real call recordings
- real transcripts containing personal data
- phone numbers, emails, identifiers
- customer or plant-sensitive operational data

Use synthetic or anonymized data only.
